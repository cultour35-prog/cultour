# CulTour Mobile App (Flutter)

The Flutter project now lives in:

`c:\xampp\htdocs\cultour\cultour mobile`

See that folder’s README for setup (`setup.ps1`) and API notes.

## Base URL

```
http://YOUR_PC_LAN_IP/cultour/api
```

Example: `http://192.168.1.10/cultour/api`

Use your computer’s LAN IP (not `localhost`) when testing on a physical phone.
The Android emulator can use `http://10.0.2.2/cultour/api`.
